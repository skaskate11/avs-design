# AVS Design

Статический сайт студии дизайна и ремонта AVS (Краснодар).

Публикация: GitHub Pages. Основной домен будет подключён после проверки версии на `skaskate11.github.io/avs-design/`.

## Карта исходников

Навигация по дереву репозитория; она не подтверждает текущую опубликованную версию сайта.

- [index.html](index.html) и [styles.css](styles.css): основная страница и стили.
- [showcase.js](showcase.js), [room-standard.js](room-standard.js), [room-comfort.js](room-comfort.js), [room-plus.js](room-plus.js): клиентские сценарии; поведение проверяй по коду.
- [logo-animation.html](logo-animation.html), [logo-intro.js](logo-intro.js): материалы анимации логотипа.
- [assets/](assets/): изображения, шрифты и другие ресурсы.
- [AGENTS.md](AGENTS.md): правила работы с проектом.
